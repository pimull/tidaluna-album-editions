Hi everyone! I've been working on a TidaLuna plugin called Album Editions, inspired by Roon's album version browser.

I saw some discussions on Reddit about TIDAL not showing all the available versions of an album, which made me want to build something to help find them. It combines Other Versions, search and artist albums into one list. You can compare editions, see the bit depth and sample rate of the first track, and open each release inside TIDAL.

I've attached a couple of screenshots showing The Dark Side of the Moon and Random Access Memories. I'm getting the first public release ready now.

This is my first programming project. I've been building it with AI assistance while learning how the code works, so feedback and code reviews would be really helpful.
